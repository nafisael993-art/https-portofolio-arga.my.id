# Portfolio - Arga Dev (Darma Putra Anugrah)

Website portofolio resmi **Darma Putra Anugrah** (Arga), pelajar SMK PGRI 1 Sidoarjo jurusan Teknik Pemesinan yang berfokus pada pengembangan layanan digital dan pemrograman web mandiri.

🌐 **Live URL**: [https://portofolio-arga.my.id](https://portofolio-arga.my.id)

---

## 📁 Struktur Berkas Repositori

```text
├── index.html                 # Halaman utama portofolio (Entry point)
├── manifest.webmanifest       # PWA Web Manifest & App Identity
├── favicon.ico                # Favicon standar browser (multi-resolution)
├── favicon-16x16.png          # Icon browser tab kecil (16x16)
├── favicon-32x32.png          # Icon browser tab standar (32x32)
├── apple-touch-icon.png       # Icon shortcut iOS / Safari (180x180)
├── android-chrome-192x192.png # Icon PWA Android (192x192)
├── android-chrome-512x512.png # Icon PWA Android HD (512x512)
├── images/
│   ├── pp-dev.png             # Foto profil resolusi tinggi (PNG transparan)
│   └── pp-dev.webp            # Foto profil optimal web (WebP)
└── README.md                  # Dokumentasi repositori
```

---

## ✨ Fitur & Pembaruan
- **Website Icon & Favicon Suite**: Terintegrasi penuh dengan foto profil personal berformat transparan resolusi tinggi (mendukung Desktop, Android Chrome PWA, dan Apple Touch Icon).
- **Struktur Standar**: Standardisasi berkas utama ke `index.html` untuk kompatibilitas penuh dengan GitHub Pages, Vercel, Netlify, atau web server lainnya.
